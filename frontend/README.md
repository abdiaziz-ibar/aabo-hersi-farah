# Aabo

- `frontend/` — React (Vite) web app, standalone
- `backend/` — Node.js (Express) API, standalone, uses Neon Postgres
- `app/`, `src/` — Expo (React Native) mobile app

Each folder has its own README and `npm install`. Run the backend first
(`backend/.env` with your Neon `DATABASE_URL`), then the frontend.
